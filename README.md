\# PRODIGY\_DS\_TASK\_05



\## Traffic Accident Data Analysis



This project analyzes US traffic accident data to identify patterns related to accident severity, weather conditions, time of day, road conditions, and accident hotspots using Python and data visualization.



\## Technologies Used



\- Python

\- Pandas

\- Matplotlib

\- Seaborn

\- Git \& GitHub



\## Dataset



The project uses the US Accidents dataset.



Dataset Source:

https://www.kaggle.com/datasets/sobhanmoosavi/us-accidents



The original dataset is not included in this repository because of its large file size.
